# 云科电气独立站｜需求 RPD 文档

> 版本 V1.0｜分析日期 2026-07-19｜产品性质：电气设备出口独立站，不是自治智能体

## 1. 目标与受众

以英文为主、中文为辅，为海外采购经理、EPC、工程商和经销商提供可信的产品与项目证据，促成询价、咨询和联系；内部运营人员负责内容与线索处理。

## 2. 内容范围

五类产品：12—40.5kV 中压开关柜、≤400V 低压开关柜、10—35kV 变压器、预制舱/箱式变电站、新能源电气。站点还应提供企业能力、应用市场、案例、FAQ、联系方式和询价表单。

## 3. 功能需求

| 编号 | 需求 | 优先级 | 验收 |
|---|---|---:|---|
| YK-01 | 英文主站与 `/zh/` 中文内容 | P0 | 关键页面语言对应；链接、标题和元数据正确 |
| YK-02 | 产品总览、分类和技术规格详情 | P0 | 参数可读、单位一致、无未经证实的性能承诺 |
| YK-03 | 市场/应用、项目案例、工厂与检测证据 | P0 | 图片/证书/案例来源可追溯；占位内容不上线 |
| YK-04 | 报价、咨询、联系表单与邮件通知 | P0 | 必填/反垃圾/同意有效；线索送达可验证；失败不丢失 |
| YK-05 | SEO、结构化数据、重定向和站点地图 | P0 | 可索引页面规范；多语言 canonical/hreflang 正确 |
| YK-06 | 内容后台、案例类型和运营更新 | P1 | 非技术人员可更新；发布前可预览 |
| YK-07 | 安全、备份、监控与隐私 | P0 | TLS、最小插件、备份恢复、隐私告知和表单留存 |

## 4. 内容与品牌约束

联系页保持简洁；产品总览清晰；案例用网格；中英文名称一致；“100+ 国家”等表述仅在有证据时使用。IEC、SGS/BV/Intertek 等认证/检验陈述必须与可提供文件一致，不沿用宣传册中未验证的 ISO/CE/CCC 等主张。

## 5. 当前状态与上线门槛

WordPress 主题、核心插件、双语内容、五类产品、市场页、4 个案例和表单测试已完成本地基线。正式产品/工厂/项目/认证图片、最终联系方式、域名主机、SMTP、真实表单送达、法律文案和 SEO 抓取仍需客户确认。

## 6. 需求依据

依据原项目 AGENTS、PRODUCT、README、架构/交付文档、企业宣传册、竞品分析和独立站资料整理。原始宣传材料的主张不自动视为已核验证据。
