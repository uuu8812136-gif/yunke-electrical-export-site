# 云科电气独立站｜项目开发文档

## 1. 代码结构

项目使用 Docker 管理 WordPress/MySQL/Nginx；自定义主题位于 `yke-global`，业务插件位于 `yke-site-core`。开发前先阅读原仓库 AGENTS 约束，它定义了页面结构、文案和证据边界。

## 2. 本地开发

从示例环境文件创建本地配置，启动 Docker 服务，安装/启用主题、插件、Polylang 和表单插件，导入本地内容后访问中英文页面。不得把本地管理员、数据库或 SMTP 凭据写进代码。

## 3. 修改原则

- 布局/样式改主题；产品、案例、表单等业务逻辑改核心插件；内容在 WordPress 后台维护。
- 新字段必须同步模板、REST/后台表单、校验、转义、迁移和双语展示。
- 所有对外主张先获得证据与业务批准；不从旧宣传册自动复制认证或覆盖国家数。
- 联系页、产品总览、案例网格和双语命名遵循既有产品约束。

## 4. 验证

运行仓库已有 curl、Playwright 和表单测试；人工检查桌面/移动、多语言切换、404/重定向、键盘可访问、图片替代文本、表单成功/失败、邮件送达、垃圾拦截和 SEO 标签。

## 5. 上线清单

替换全部占位图片与联系信息；核验证书/案例；配置正式域名、TLS、SMTP、隐私/条款、备份、监控和分析；提交站点地图并检查索引。上线后以真实询盘送达测试为最终验收。
