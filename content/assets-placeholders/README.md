# Placeholder Assets

This folder contains non-final visual placeholders derived from the top-level source PDF.

Structure:

- `pdf-pages/`: raw per-page PNG exports from the company brochure PDF
- `selected/`: renamed page-based assets intended for quick content mapping and preview work
- `manifest.json`: machine-readable index of selected assets and their source pages

These files are useful for:

- early WordPress media imports
- static preview work before final photography arrives
- page planning and section-to-asset mapping

Limitations:

- the images are brochure-page captures, not production-ready web crops
- typography is embedded in the image, so they should be replaced with real photography or cleaner derived crops later
- no theme or plugin code depends on these assets directly
